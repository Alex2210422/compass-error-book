# Compass Error Book

Calculates gyro and magnetic compass error from celestial bearings and mirrors the ship's compass error book.

APK is built automatically by GitHub Actions on every push to `main` and published under **Releases**.

Keep this repository **private**: `keystore/release.p12` is the app signing key. Every update must be signed with the same key, so keep a backup of it.
